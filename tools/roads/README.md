# لایهٔ راه‌های ایران (دادهٔ OpenStreetMap)

افزودن **شبکهٔ راه‌های بین‌شهری واقعی ایران** به «اطلس باربری ایران» (`iran-freight-atlas-v3.html`).

## منبع داده

- **OpenStreetMap** از طریق Overpass API — مجوز: © OpenStreetMap contributors (ODbL)
- کلاس‌ها: `motorway` (آزادراه)، `trunk` (بزرگراه/شریانی)، `primary` (راه اصلی)
- فقط قطعات ≥ ۰٫۸–۲ کیلومتر (شبکهٔ بین‌شهری)، ساده‌سازی Douglas-Peucker با تلورانس ۱۸۰m تا ۱٫۱km
- نتیجهٔ نهایی: **۱۱٬۱۲۲ خط و ۲۶٬۷۷۷ نقطه** (از ۵۶٬۸۳۲ way خام و ۹۳۶ هزار نقطه)

## فایل‌ها

| فایل | نقش |
|---|---|
| `fetch.mjs` | دریافت هندسهٔ خام از Overpass (تکه‌تکه) → `raw-*.json` |
| `build.mjs` | فیلتر طول + ساده‌سازی + کدگذاری دلتا/zigzag/base36 + gzip/base64 → `iran-roads-packed.json` |
| `to-geojson.mjs` | تبدیل بسته به GeoJSON استاندارد (RFC 7946) → `iran-roads.geojson` |
| `layer.js` | ماژول ران‌تایم لایه (تزریق‌شده در HTML) |
| `inject.mjs` | تزریق idempotent داده + ماژول + قلاب موتور به `iran-freight-atlas-v3.html` |

پارامترهای قابل تنظیم با متغیر محیطی: `TOL0/TOL1/TOL2` (تلورانس ساده‌سازی) و `MIN0/MIN1/MIN2` (حداقل طول به کیلومتر).

## اجرای دوباره

```bash
cd tools/roads
node fetch.mjs motorway
node fetch.mjs trunk
node fetch.mjs primary-sw && node fetch.mjs primary-se && node fetch.mjs primary-nw && node fetch.mjs primary-ne
node build.mjs          # → iran-roads-packed.json
node to-geojson.mjs     # → iran-roads.geojson (اختیاری)
node inject.mjs         # تزریق در ../../iran-freight-atlas-v3.html
```

`fetch.mjs` هر تکه را در `raw-*.json` کش می‌کند؛ اجرای دوباره در صورت وجود فایل، از شبکه نمی‌خواند. (`raw-*.json` در گیت نگه‌داشته نمی‌شود.)

## معماری لایه در صفحه

- **قلاب موتور:** `inject.mjs` رشتهٔ `this.baseDirty&&(this._drawBase(),this.baseDirty=!1)` را یک‌بار به فراخوانی `globalThis.__IR_ROADS(this)` تغییر می‌دهد؛ یعنی پس از هر رسم لایهٔ پایه (که با dirty-flag کش می‌شود) لایهٔ راه‌ها هم روی همان کانواس رسم می‌شود.
- **پروجکشن:** مسیر سریع affine با همان ریاضی موتور (`x = A + lon·π/180·scale`, `y = C + mercY(lat)·scale`)؛ در اولین رسم با `engine.project` مقایسه و در صورت اختلاف >۰٫۷۵px به مسیر پیش‌فرض برمی‌گردد (فعلاً `fastPath: true`).
- **کش و کالینگ:** هر way فقط وقتی `viewVersion` تغییر کند دوباره پروجکت می‌شود؛ حذف خارج از کادر با bbox در فضای پروجکشن.
- **LOD:** آزادراه در همهٔ زوم‌ها؛ بزرگراه از z≥2.0؛ راه اصلی از z≥3.2 (نرخ‌های `LOD` در `layer.js`).
- **یکپارچگی با کنترل‌های خود اپ:** ردیف «جاده‌ای» پنل اپ، لایه را خاموش/روشن می‌کند (MutationObserver + خواندن تنبل).
- **پنل:** «راه‌های ایران» با سوئیچ، راهنمای رنگ‌ها، وضعیت زوم و انتساب OSM؛ با توکن‌های CSS خود اپ تم‌پذیر است.
- **کارایی:** رسم روی لایهٔ پایهٔ کش‌شده انجام می‌شود؛ روی سندباکس تک‌هسته‌ای ≈۱۲ms در زوم اولیه و ≈۰٫۵ms پس از کالینگ؛ پارس یک‌بارهٔ داده ~۰٫۴s و غیرمسدودکننده (پس از mount، روی رشتهٔ اصلی).

## تست

`perf/verify-roads.mjs` (Playwright) این‌ها را بررسی می‌کند: خطاهای کنسول/صفحه، پیکسل‌های راه روی کانواس در نقاط پروجکت‌شده، سوئیچ پنل، ردیف «جاده‌ای»، کالینگ در زوم و درگ، و رگرسیون کارایی idle. خروجی تصویری: `perf/roads-preview.png`.

## محدودیت‌ها

- هندسه ساده‌سازی‌شده است (۱۸۰m تا ۱٫۱km) — برای مقیاس کشور و زوم‌های متعارف مناسب است، نه نقشهٔ ناوبری.
- فقط راه‌های بین‌شهری (ramp/link و خیابان‌های شهری حذف شده‌اند).
- `DecompressionStream` مرورگر برای بازکردن بسته لازم است (کروم ۸۰+، فایرفاکس ۱۱۳+، سافاری ۱۶٫۴+)؛ در غیر این صورت لایه بی‌سر‌و‌صدا غیرفعال می‌ماند.
